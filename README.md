# Kour.io Color Change Name

Это пользовательский скрипт для Tampermonkey/Greasemonkey, который меняет цвет Вашего никнейма в игре kour.io каждые 30 секунд.

## Как настроить

Перед использованием отредактируйте файл `Color_change_name.js`:

- Измените переменную `nickname` на желаемый ник (по умолчанию: `"Nickname"`).
- Измените переменную `colorChangeTime` на интервал в миллисекундах для смены цвета (по умолчанию: `30000` мс = 30 секунд).

## Установка

1. Установите расширение для управления пользовательскими скриптами, такое как [Tampermonkey](https://www.tampermonkey.net/) (для Chrome, Edge, Firefox и т.д.) или [Greasemonkey](https://www.greasespot.net/) (для Firefox).
2. Нажмите [эту ссылку](https://greasyfork.org/ru/scripts/580279-kour-io-color-change-name/) для установки скрипта напрямую (если у вас установлен менеджер скриптов) или скачайте файл `Color_change_name.js` и установите его вручную через опцию "Добавить новый скрипт" в вашем менеджере скриптов.
3. Зайдите в игру kour.io, теперь, когда Вы зайдёте в матч, то скрипт начнёт изменять Ваш никнейм, согласно его алгоритму.
